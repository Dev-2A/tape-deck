# 📼 Tape Deck

YouTube URL을 카세트테이프 한 면씩 담아 재생하는 감성 음악 플레이어.

> 실용성보다 미학에 진지한 프로젝트. 재생 중 릴이 돌아가고, 볼륨은 노브로 돌리고, A면을 다 들으면 B면으로 뒤집는다.

## 🎯 주요 기능

- 🎵 YouTube URL을 한 면당 여러 개 담아 카세트테이프로 만들기
- 📼 진짜 카세트테이프 모양 SVG UI — 재생 중 릴이 회전
- 🎚️ 드래그해서 돌리는 볼륨 노브
- 🔄 A면 / B면 전환 (테이프 뒤집기 애니메이션)
- 🎨 테이프 케이스 커버 직접 디자인 (색상 · 이모지 · 제목)
- 💾 "내 테이프 컬렉션" 로컬 저장 (IndexedDB)

## 🛠️ 기술 스택

- React 18 + Vite
- Tailwind CSS v4
- SVG 기반 애니메이션
- YouTube IFrame Player API
- Dexie.js (IndexedDB)
- GitHub Pages
